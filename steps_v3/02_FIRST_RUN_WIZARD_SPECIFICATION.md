# 🪄 مواصفات معالج الإعداد الأولي (First-Run Setup Wizard UI/UX)

## 🎨 1. تجربة المستخدم والهوية البصرية (Visual Design)

- **الهوية الأساسية:** مبنية على نظام **Spatial UI (VisionOS Style)** المعتمد في المشروع.
- **الشعار والترويسة العلوية:** 
  - شعار واسم: **شركة تقنية السحابة (Taqniya Cloud)**.
  - العنوان الفرعي: *"تهيئة وتفعيل منظومة السحابة لإدارة نقاط البيع والمتاجر"*.

---

## 🧭 2. خطوات المعالج التفاعلي (Interactive Flow)

### 🔹 المرحلة 1: تحديد نوع الجهاز (Device Role Selection)
تظهر بطاقتان زجاجيتان عريضتان (Floating Cards):
- **البطاقة أ (الجهاز الرئيسي / السيرفر):**
  - الأيقونة: 🖥️
  - العنوان: *"تثبيت كخادم رئيسي (Master Server)"*
  - الوصف: *"هذا الجهاز هو السيرفر الأساسي للمحل، وسيحمل قاعدة البيانات وخادم الويب وإعدادات الشبكة."*
- **البطاقة ب (جهاز كاشير فرعي):**
  - الأيقونة: 💻
  - العنوان: *"ربط كشاشة كاشير فرعية (Cashier Terminal)"*
  - الوصف: *"هذا الجهاز متصل بنفس شبكة المحل وسيتصل بالسيرفر الرئيسي مباشرة دون الحاجة لخادم محلي."*

---

### 🔹 المرحلة 2 (أ): نموذج إعداد السيرفر الرئيسي (Master Server Form)

يحتوي النموذج على 3 أقسام رئيسية مقسمة بذكاء:

#### 1. هوية العميل وبيانات المتجر (Client Branding):
- **اسم المتجر / النشاط التجاري:** (مثال: `طيبة التاجوري` أو اسم المتجر الجديد).
- **شعار المتجر (Store Logo Upload):** 
  - حقل رفع صور بالسحب والإفلات (Drag & Drop) مع معاينة فورية للصورة المصغرة.
  - يتم حفظ الشعار برمجياً في مجلد التخزين وتعيينه كشعار رئيسي للمتجر والفواتير والإيصالات.

#### 2. قاعدة البيانات المركزية (MySQL Configuration):
- **اسم المضيف (Host):** افتراضياً `127.0.0.1`.
- **المنفذ (Port):** افتراضياً `3306`.
- **اسم قاعدة البيانات:** افتراضياً `perfumes_v2` (أو اسم مخصص).
- **اسم المستخدم وكلمة المرور:** (التي تم إنشاؤها عبر MySQL Workbench).
- **زر ذكي:** ⚡ *"فحص الاتصال بقاعدة البيانات"* (يعطي وميضاً أخضر فورياً عند نجاح الاتصال، أو رسالة توضيحية في حال الخطأ).

#### 3. إعدادات الشبكة والنطاق المحلي (Local Domain):
- **النطاق المحلي المخصص:** حقل مدخل يكتب فيه تلقائياً `tajori.store` (مع إمكانية تغييره بحسب رغبة العميل).

---

### 🔹 المرحلة 2 (ب): نموذج ربط الجهاز الفرعي (Cashier Client Form)

- **عنوان السيرفر الرئيسي (Server IP or Domain):**
  - حقل كتابة واضح: (مثال: `192.168.1.15` أو `tajori.store`).
- **زر الاكتشاف التلقائي:** 🔍 *"البحث التلقائي عن السيرفر في الشبكة المحلية (Auto-Scan LAN)"*.
- **زر الفحص:** ⚡ *"فحص الاتصال بالسيرفر"* (يرسل طلب `ping / health-check` سريع للتأكد من استجابة خادم السيرفر الرئيسي).

---

## ⚡ 3. الإجراءات البرمجية الصامتة المنفذة في الخلفية (Silent Execution Engine)

عند الضغط على زر **"بدء التثبيت والتفعيل النهائي"** في الجهاز الرئيسي:

1. **كتابة وحفظ المتغيرات البيئية (`.env`):**
   - تحديث متغيرات الاتصال `DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`.
   - ضبط `APP_NAME` باسم متجر العميل (مثلاً: *"طيبة التاجوري"*).
   - تحديث `APP_URL=https://tajori.store`.

2. **حفظ هوية وشعار العميل في جدول الإعدادات (`settings`):**
   - نقل ملف الشعار إلى مسار التخزين المعتمد:
     `storage/app/public/branding/logo.png`
   - تسجيل إعدادات:
     - `store_name` -> اسم المتجر.
     - `store_logo` -> مسار الشعار.

3. **تنفيذ الأوامر البرمجية للارافيل:**
   ```bash
   php artisan key:generate
   php artisan migrate --force
   php artisan db:seed --class=CoreSystemSeeder --force
   php artisan optimize
   ```

4. **تعديل ملف `hosts` لويندوز:**
   - إضافة سطر التوجيه:
     `127.0.0.1 tajori.store`

5. **توليد شهادات SSL وتفعيل HTTPS:**
   - استدعاء سكريبت `mkcert.exe` لتثبيت الشهادة المحلية الموثوقة وتفعيل الـ SSL في Apache.

6. **بدء الخدمات التلقائية لويندوز:**
   - تشغيل خدمة Apache 2.4.
   - تشغيل خدمة Redis.
   - تشغيل خدمة محرك الطابعات الحرارية (Thermal Printer Daemon).

## 🎉 4. شاشة الإطلاق النهائي (Ready & Launch Screen)

- تظهر علامة النجاح الخضراء الكبيرة مع عبارة:
  *"تم تهيئة وتشغيل منظومة السحابة بنجاح!"*
- يظهر بطاقة ملخص تحتوي على:
  - اسم المتجر والشعار.
  - الرابط الداخلي المباشر: `https://tajori.store`.
  - عنوان الـ IP المحلي للسيرفر: `https://192.168.1.15`.
  - **كود QR كبير وواضح:** يمكن لمسؤولي المحل مسحه بكاميرا الهاتف أو الأجهزة اللوحية (Tablets) للبدء في الجرد والبيع فوراً!
- زر كبير: **"الدخول إلى لوحة التحكم والبيع الآن 🚀"**.
