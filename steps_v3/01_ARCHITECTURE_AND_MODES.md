# ⚙️ المعمارية التقنية وأنماط التشغيل (System Architecture & Modes)

## 🏗️ 1. المكدس التقني المعتمد (Enterprise Stack)

```text
┌─────────────────────────────────────────────────────────────────┐
│               Electron Desktop Shell (Native .EXE)              │
│       (Chromium Engine + Native Title Bar + OS Integrations)    │
└────────────────────────────────┬────────────────────────────────┘
                                 │
     ┌───────────────────────────┴───────────────────────────┐
     ▼                                                       ▼
[نمط 1: السيرفر الرئيسي (Master)]            [نمط 2: الكاشير الفرعي (Client)]
 - Apache 2.4 (Ports 80 & 443 SSL)           - لا يحتاج Apache ولا MySQL ولا Redis
 - PHP 8.4 (OPcache Enabled)                 - يتصل فورياً بسيرفر المحل عبر LAN
 - Redis Server (Port 6379 - Sessions/Cache) - خفيف جداً، سريع الإقلاع والاستجابة
 - MySQL Server (Port 3306)
 - محرك الطباعة الحراري (Port 9124 / TSPL)
```

## 🖥️ 2. تفصيل نمطي التشغيل (Dual Operational Modes)

### النمط الأول: الجهاز الرئيسي (Central Server / Master Node)
- **المكان:** يثبت على جهاز السيرفر الأساسي داخل المحل أو الإدارة.
- **المسؤوليات التقنية:**
  1. **الخادم المحلي (Web Server):** خادم **Apache 2.4** معد ومربوط بوحدات PHP 8.4 و SSL.
  2. **قاعدة البيانات المركزية (SSoT Database):** خادم **MySQL** يعمل محلياً ويحتوي على كافة الفواتير، المنتجات، العملاء والمخزون.
  3. **الذاكرة السريعة (In-Memory Cache):** خادم **Redis** لإدارة جلسات أجهزة الكاشير المتعددة ومنع تضارب الفواتير المتزامنة.
  4. **محرك الباركود والطباعة:** خدمة **Node Print Service** لإرسال الأوامر المباشرة للطابعات الحرارية عبر بروتوكولات TSPL/ESC-POS.
  5. **اكتشاف الشبكة (LAN Discovery):** يكتشف الـ Local IP (مثل `192.168.1.15`) ويطبعه مع رمز QR لربط الأجهزة الأخرى.

### النمط الثاني: جهاز الكاشير الفرعي (Cashier Terminal / Client Node)
- **المكان:** يثبت على أي جهاز كمبيوتر إضافي في المحل (كاشير 2، كاشير 3، نقطة استلام، شاشة جرد).
- **المسؤوليات التقنية:**
  1. **تثبيت صامت فوري (Zero-Server Footprint):** لا يحتاج تثبيت Apache ولا MySQL ولا PHP.
  2. **حلقة وصل الشبكة (Network Bridging):** يحتاج فقط إلى إدخال عنوان السيرفر الرئيسي (مثل: `192.168.1.15` أو `tajori.store`).
  3. **مزامنة ملف Hosts:** يقوم بتوجيه النطاق محلياً إلى عنوان السيرفر.
  4. **الأمان والتخزين:** يتصل مباشرة بجلسة السيرفر المركزي المؤمنة عبر الـ HTTPS.

## 🪟 3. خصائص تطبيق سطح المكتب (Electron Desktop Capabilities)

1. **التحكم الصارم بالنافذة (Single-Window POS Enclosure):**
   - منع فتح نوافذ مكررة من البرنامج عبر `app.requestSingleInstanceLock()`.
   - قفل شريط قوائم ويندوز الكلاسيكية القديمة (`Menu.setApplicationMenu(null)`).
   - ملء الشاشة بنقرة زر (`F11`) مع دعم كامل للوضعين الداكن والفاتح.
2. **التكامل مع العتاد الفيزيائي (Direct Hardware Interfacing):**
   - الطباعة الصامتة للفواتير دون ظهور مربعات حوار الطابعات المزعجة.
   - تشغيل درج الكاشير النقدي (Cash Drawer Kick) فور إتمام عملية البيع.
   - قراءة ماسحات الباركود (Barcode USB Scanners) بأقصى سرعة استجابة.
3. **حماية مسارات النظام:**
   - منع فتح الروابط الخارجية داخل واجهة الكاشير، وتحويلها تلقائياً لمتصفح النظام الافتراضي عبر `shell.openExternal`.
