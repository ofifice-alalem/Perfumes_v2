# 🚀 خطة ومراحل التنفيذ الفعلي (Implementation Roadmap & Milestones)

## 📌 استراتيجية الفرع (Git Branch Strategy)

سيتم تنفيذ كافة الأعمال البرمجية ضمن فرع مخصص ومستقل تماماً لضمان سلامة النسخة الرئيسية:
```bash
git checkout -b feature/desktop-installer-wizard
```

---

## 🛠️ تفصيل مراحل العمل البرمجي (Phased Execution)

### المرحلة 1: بنية واجهات التهيئة الخلفية (Backend Setup API)
1. **إنشاء Controller مخصص للمهندس والفني:**
   - المسار: `app/Http/Controllers/SetupWizardController.php`
2. **الـ Endpoints المعتمدة:**
   - `GET /api/setup/status`: لفحص هل النظام مهيأ مسبقاً أم يحتاج لتشغيل الـ Wizard.
   - `POST /api/setup/test-db`: لاختبار صحة بيانات MySQL قبل الحفظ.
   - `POST /api/setup/test-host`: لفحص اتصال الجهاز الفرعي بعنوان السيرفر الرئيسي.
   - `POST /api/setup/apply-master`: لتطبيق إعدادات السيرفر الرئيسي وتحديث `.env` ورفع الشعار وتشغيل الترحيل.
   - `POST /api/setup/apply-client`: لتطبيق إعدادات الجهاز الفرعي.
3. **طبقة الحماية (Security Gate):**
   - بمجرد اكتمال التهيئة، يتم غلق هذه المسارات برمجياً عبر وضع علامة `SETUP_COMPLETED=true` في قاعدة البيانات وملف الإعدادات لمنع العبث بها لاحقاً.

---

### المرحلة 2: بناء واجهة المعالج الرسومية (Frontend Wizard Component)
1. **تصميم الصفحة:**
   - المسار: `resources/js/pages/Setup/Wizard.tsx`
2. **المكونات التفاعلية:**
   - استخدام بطاقات `SpatialCard` ونظام الزجاج الفاخر (Glassmorphism).
   - نموذج اختيار نوع الجهاز (رئيسي / فرعي).
   - مكون رفع الشعار بالسحب والإفلات وتغيير الحجم.
   - عداد خطوات (Step Progress Bar) مع تأثيرات انتقال سلسة بين المراحل.
   - شريط تقدم مباشر لعملية التثبيت (Installation Progress Bar).

---

### المرحلة 3: سكريبتات الأتمتة لويندوز (Windows Silent Automation Scripts)
1. **أتمتة ملف Hosts:**
   - سكريبت PowerShell لإضافة أو تعديل نطاق المتجر المخصص بدون تدخل يدوي.
2. **أتمتة شهادات الـ SSL:**
   - دمج محرك `mkcert.exe` لتوليد شهادات صامتة وتثبيتها في مخزن الشهادات الموثوقة لويندوز (Root CA).
3. **أتمتة خدمات Windows:**
   - تشغيل Apache و Redis ومحرك الطباعة كخدمات خلفية بدون ظهور شاشات CMD سوداء مزعجة للعميل.

---

### المرحلة 4: غلاف سطح المكتب المزدوج (Dual Electron Desktop Launchers) — [مكتملة ✅]
1. **المحرك الرئيسي (`electron/main.js`):**
   - يدعم الفحص التلقائي للمنافذ (`probePort`).
   - إذا كان أباتشي يعمل -> يتصل به مباشرة.
   - إذا كان أباتشي متوقفاً لأول مرة -> يشغل خادم PHP صامت مؤقت على المنفذ `8181` لعرض شاشة الإعداد فوراً بدون متصفح.
2. **مشغل المبيعات اليومي (`electron/launcher-pos.js`):**
   - تشغيل مباشر للمنظومة وشاشات الكاشير والمبيعات (`npm run desktop:pos`).
3. **مشغل إعدادات السيرفر والصيانة (`electron/launcher-settings.js`):**
   - تشغيل مباشر لأداة ضبط السيرفر وقاعدة البيانات للفني (`npm run desktop:settings`).

---

### المرحلة 5: التحزيم وبناء ملف التثبيت (.EXE Packaging) — [مكتملة الإعداد ✅]
1. **إعداد `electron-builder` في `package.json`:**
   - تجهيز سكريبت البناء لإنتاج ملف التثبيت:
     `Taqniya Cloud System Setup 1.0.0.exe` في مجلد `dist/`.
   - دمج الأيقونات والشعارات الرسمية لـ **شركة تقنية السحابة**.
   - إضافة خيارات إنشاء اختصار على سطح المكتب وقائمة Start تلقائياً.
   - أمر التجميع النهائي: `npm run build:exe`.

---

### المرحلة 6: الفحص والاختبار الميداني (Quality Assurance & Verification)
1. تجربة التثبيت كجهاز رئيسي وفحص:
   - إنشاء قاعدة البيانات والجداول بنجاح.
   - ظهور اسم متجر العميل وشعاره في شاشة الدخول والفواتير.
   - عمل خادم Apache و HTTPS محلياً.
2. تجربة التثبيت كجهاز كاشير فرعي:
   - ربطه بـ IP الجهاز الرئيسي والتأكد من فتح شاشة البيع بدون أي خادم محلي.
