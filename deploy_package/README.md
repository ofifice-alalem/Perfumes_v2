# دليل تشغيل منظومة السحابة على أي جهاز جديد (Offline)

يحتوي هذا المجلد على كل ما يلزم لتشغيل المنظومة بكامل كفاءتها على أي جهاز بدون إنترنت وبدون الحاجة لتثبيت أي برامج إضافية عدا **Docker Desktop**.

---

## 📋 المتطلبات المسبقة:
- تثبيت **Docker Desktop** (أو Docker Engine) على الجهاز الجديد فقط.

---

## 🚀 طريقة التشغيل:

### 1. على نظام ويندوز (Windows):
- انقر مرتين على: **`run_docker.bat`**
- سيعمل البرنامج تلقائياً ويفتح المتصفح على: `http://localhost:8000`

### 2. على نظام لينكس أو ماك (Linux / macOS):
- افتح الطرفية (Terminal) في هذا المجلد ونفذ:
  ```bash
  chmod +x run_docker.sh
  ./run_docker.sh
  ```
- أو عبر الأمرين المباشرين:
  ```bash
  docker load -i perfumes_bundle_offline.tar
  docker compose up -d
  ```
- افتح المتصفح على: `http://localhost:8000`

---

## 🔑 بيانات تسجيل الدخول الافتراضية:
- **اسم المستخدم (Username):** `admin`
- **كلمة المرور (Password):** `password`

---

## 🛑 لإيقاف المنظومة:
- **ويندوز:** انقر مرتين على **`stop_docker.bat`**
- **لينكس / ماك:** نفّذ `docker compose stop`

> 💾 **ملاحظة أمان البيانات:** جميع الفواتير والمبيعات وإعدادات المتجر تُحفظ في قاعدة بيانات دائمة وآمنة ولا تُمس عند إيقاف التشغيل.
