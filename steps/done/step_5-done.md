# ✅ Step 5 — الفواتير ونقطة البيع

## Features المنجزة

### نظام نقطة البيع (POS System)
- **واجهة POS كاملة**: تصميم احترافي مقسم لجانبين (إدخال المنتجات + الفاتورة)
- **دعم اللمس**: جميع العناصر محسنة للشاشات التفاعلية مع أحجام مناسبة
- **تصميم RTL**: دعم كامل للعربية مع تخطيط من اليمين لليسار

### أنواع المنتجات وآلية البيع

#### 1. العطور الزيتية (`tier_based`)
- **آلية التحديد**: `selectedProduct.selling_type === 'tier_based'`
- **نوع البيع**: `tier_decant` (تقسيم زيتي) - يُحدد تلقائياً
- **نظام التسعير**: أسعار متدرجة ثابتة من `price_tier.tier_prices`
- **الأحجام**: محددة مسبقاً (5مل، 10مل، 15مل، 20مل، 30مل، 50مل، 100مل)
- **حساب الكمية**: من `size.value` (حجم الحاوية المختارة)
- **حساب السعر**: سعر ثابت لكل حجم (ليس ضرب في الكمية)
- **مثال**: عطر Lacoste White - حجم 30مل بسعر 15 دينار (سعر ثابت)

#### 2. العطور الأصلية (`original perfumes`)
- **آلية التحديد**: `selectedProduct.category.unit === 'ml' && !isTier`
- **خيارات البيع المتاحة**:

  **أ) تقسيم (`unit_decant`)** - الخيار الافتراضي:
  - السعر: `price_per_unit_regular/vip` × الحجم المطلوب
  - الأحجام: قابلة للتخصيص (يمكن إدخال أي رقم) أو محددة مسبقاً
  - المرونة: بيع أي كمية بالمليلتر
  - مثال: Dior Sauvage - 25مل × 2 دينار/مل = 50 دينار

  **ب) عبوة كاملة (`full_bottle`)**:
  - السعر: `full_bottle_regular/vip` (سعر ثابت للعبوة)
  - الحجم: `original_perfume_detail.bottle_volume` (حجم العبوة الأصلي)
  - الاستخدام: بيع العبوة بالكامل دون تقسيم
  - مثال: Dior Sauvage عبوة 100مل بسعر 180 دينار (سعر ثابت)

#### 3. المنتجات الأخرى (وشق، مبخرة، بخور، عود، إلخ)
- **آلية التحديد**: `selling_type !== 'tier_based' && category.unit !== 'ml'`
- **نوع البيع**: `unit_based` (بالوحدة/القطعة) - يُحدد تلقائياً
- **نظام التسعير**: `price_per_unit_regular/vip` × الكمية المطلوبة
- **وحدة القياس**: حسب نوع المنتج (قطعة، جرام، علبة، إلخ)
- **المرونة**: بيع أي كمية مطلوبة
- **أمثلة**:
  - وشق فاخر: 5 قطع × 3 دينار/قطعة = 15 دينار
  - بخور عود: 200 جرام × 0.05 دينار/جرام = 10 دينار
  - مبخرة صغيرة: 2 قطعة × 8 دينار/قطعة = 16 دينار

### آلية الاختيار التلقائي لنوع البيع
```typescript
// العطور الزيتية - اختيار تلقائي
if (isTier) {
  saleType = 'tier_decant'; // تلقائياً
}

// العطور الأصلية - افتراضي "تقسيم"
if (isOriginal) {
  saleType = 'unit_decant'; // افتراضي
  // يمكن تغييره إلى 'full_bottle' يدوياً
}

// المنتجات الأخرى - اختيار تلقائي
if (!isTier && !isOriginal) {
  saleType = 'unit_based'; // تلقائياً
}
```

### إدارة العملاء
- **اختيار العميل**: من قائمة العملاء أو زبون نقدي
- **نوع العميل**: عادي أو VIP مع تأثير على الأسعار
- **أزرار محسنة**: أحجام كبيرة للمس (h-14 مع text-base)

### إدارة السلة والفاتورة
- **تجميع العناصر المتشابهة**: عرض منظم للمنتجات المتكررة
- **تعديل الكميات**: عبر Number Pad Modal تفاعلي
- **حذف العناصر**: أزرار حذف واضحة ومميزة (bg-red-500)
- **جدول منظم**: 6 أعمدة (عدد، المنتج، حجم، سعر الوحدة، الإجمالي، إجراءات)

### نظام المدفوعات
- **طرق دفع متعددة**: دعم جميع وسائل الدفع المتاحة
- **دفع جزئي**: إمكانية تقسيم المبلغ على عدة طرق
- **تحديث تلقائي**: تحديث المدفوعات عند تغيير إجمالي الفاتورة
- **تحرير المدفوعات**: إمكانية تعديل أو حذف المدفوعات

### المكونات التفاعلية (UI Components)
- **NumberPadModal**: لوحة أرقام تفاعلية محسنة للمس
  - أزرار دائرية كبيرة (w-20 h-20)
  - دعم لوحة المفاتيح
  - زر تأكيد محسن مع تدرج لوني
- **SizeSelect**: اختيار الأحجام مع عرض الأسعار
- **SaleTypeModal**: اختيار نوع البيع بصرياً مع أوصاف

### المنتجات السريعة
- **وصول سريع**: 9 منتجات شائعة للوصول السريع
- **تصميم محسن**: أزرار بحجم مناسب (py-6, min-h-70px) بدون صور
- **ألوان مميزة**: كل منتج بلون مختلف للتمييز السريع

### مميزات متقدمة
- **تعليق الفواتير**: حفظ الفواتير غير المكتملة في localStorage
- **استعادة الفواتير**: إمكانية استكمال الفواتير المعلقة
- **موديل النجاح**: عرض تفاصيل الفاتورة بعد إتمام البيع
- **اختيار تلقائي ذكي**: لأنواع البيع حسب المنتج

### Backend Integration
- **InvoiceController**: إنشاء الفواتير مع العناصر والمدفوعات
- **Route**: `/invoices/with-items` لإرسال البيانات كاملة
- **Validation**: التحقق من صحة البيانات قبل الحفظ
- **Database Updates**: تحديث المخزون تلقائياً عند البيع
