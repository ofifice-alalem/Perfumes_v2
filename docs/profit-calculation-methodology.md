# دليل المنهجية المحاسبية والتحليلية لحساب أرباح المنتجات
**Product Profit Calculation Methodology & Real-Time Ledger Analysis**

---

## 📌 مقدمة وفكرة التقرير

في تقرير **تحليل أرباح المنتجات بالتاريخ** (`/reports/profit-analysis?active_tab=stock_profit`)، يُلاحظ الكثير من المحللين والمستخدمين وجود اختلاف بين:
1. **الربح اليدوي التقريبي**: $(\text{متوسط سعر البيع} - \text{متوسط سعر الشراء}) \times \text{صافي كمية المبيعات}$.
2. **الربح الفعلي المحسوب في التقرير**: الربح المحاسبي الدقيق المستند إلى نظام الجرد المستمر وتكلفة البضاعة المباعة اللحظية (**Perpetual Moving Average COGS**).

يوضح هذا الدليل الفارق الجوهري بين المنهجيتين مع **أمثلة عملية واقعية بالأرقام** لشرح أسباب الفارق، ولماذا يُعتبر رقم التقرير هو المرجع المالي والمحاسبي الصحيح.

---

## ⚖️ المقارنة بين المنهجيتين

| وجه المقارنة | طريقة المتوسط الدوري (الحساب اليدوي البسيط) | طريقة المتوسط المتحرك اللحظي (نظام التقرير) |
| :--- | :--- | :--- |
| **المعادلة المستخدمة** | $(\text{Avg Sale} - \text{Avg Purchase}) \times \text{Net Qty}$ | $\sum (\text{قيمة كل فاتورة} - (\text{الكمية المباعة} \times \text{تكلفة المخزون في تلك اللحظة}))$ |
| **معالجة عامل الزمن** | ❌ تتجاهل التوقيت الزمني للشحنات والمبيعات | ✅ ترتب الحركات زمنياً بالثانية وتطبق التكلفة المتوفرة وقت البيع |
| **دخول شحنات لاحقة** | ❌ تخلط تكلفة شحنات دخلت بعد البيع مع مبيعات سابقة | ✅ لا تؤثر الشحنات اللاحقة على تكلفة مبيعات حدثت قبل وصولها |
| **تفاوت أسعار البيع** | ❌ تفترض سعراً موحداً لجميع الزبائن | ✅ تحسب الربح الدقيق لكل فاتورة على حدة بعد الخصومات |
| **معالجة المرتجعات** | ❌ تقريبية وقد تشوه المتوسط العام | ✅ تعيد القطعة المرتجعة للمخزون بتكلفتها الأصلية وتعدل الربح بدقة |
| **المطابقة المحاسبية** | ⚠️ تقريبية (Approximation) وغير معتمدة مالياً | 🎯 مطابقة لمعايير المحاسبة الدولية (IFRS / GAAP) |

## 📊 أمثلة عملية توضيحية

### 🟢 المثال الأول: تغير أسعار الشراء عبر الزمن (شحنة دخلت بعد عملية البيع)

لنفترض حركة لمنتج محدد (**عطر فاخر**) خلال شهر يناير:

#### 1. سجل الحركات الزمنية:
* **01 يناير:** رصيد افتتاحي = **10 قطع** بسعر تكلفة **40 د.ل/قطعة** (إجمالي القيمة = 400 د.ل).
* **05 يناير (عملية بيع 1):** تم بيع **10 قطع** بسعر **70 د.ل/قطعة** (إجمالي الفاتورة = 700 د.ل).
  * المخزون بعد البيع = **0 قطعة**.
* **15 يناير (شحنة شراء جديدة):** تم استيراد **10 قطع** بسعر تكلفة جديد مرتفع **60 د.ل/قطعة** (إجمالي الفاتورة = 600 د.ل).
* **20 يناير (عملية بيع 2):** تم بيع **2 قطعة** بسعر **74 د.ل/قطعة** (إجمالي الفاتورة = 148 د.ل).
  * المخزون المتبقي = **8 قطع**.

---

#### 2. كيف يحسبها النظام (التقرير):
النظام يبني دفتراً زمنياً لحظياً، ويحسب ربح كل فاتورة وفق تكلفة المخزون المتاحة في نفس يوم وساعة الفاتورة:

1. **فاتورة يوم 05 يناير:**
   * تكلفة القطعة في هذا اليوم = **40 د.ل**.
   * الربح = $10 \times (70 - 40) =$ **300 د.ل**.
2. **فاتورة يوم 20 يناير:**
   * تكلفة القطعة في هذا اليوم = **60 د.ل** (من الشحنة الجديدة).
   * الربح = $2 \times (74 - 60) =$ **28 د.ل**.

$$\text{إجمالي الربح المحاسبي المحقق} = 300 + 28 = \mathbf{328\text{ د.ل}}$$

---

#### 3. كيف تُحسب يدويًا بالمعادلة التقريبية؟
إذا أخذنا المتوسطات الإجمالية كما تظهر في أعمدة الجدول:
* **متوسط سعر الشراء الإجمالي الظاهر:**
  $$\text{متوسط الشراء} = \frac{(10 \times 40) + (10 \times 60)}{10 + 10} = \frac{1000}{20} = \mathbf{50\text{ د.ل}}$$
* **متوسط سعر البيع الإجمالي الظاهر:**
  $$\text{متوسط البيع} = \frac{(10 \times 70) + (2 \times 74)}{10 + 2} = \frac{700 + 148}{12} = \frac{848}{12} = \mathbf{70.67\text{ د.ل}}$$
* **صافي الكمية المباعة:** $12$ قطعة.

**تطبيق المعادلة اليدوية:**
$$\text{الربح اليدوي} = (70.67 - 50) \times 12 = 20.67 \times 12 = \mathbf{248\text{ د.ل}}$$

> 💡 **ملاحظة التحليل:**
> الفارق هنا حدث لأن المعادلة اليدوية حملت مبيعات يوم 05 يناير تكلفة شحنة تم شراؤها يوم 15 يناير بسعر أغلى (50 د.ل بدلاً من 40 د.ل)، وهو خطأ محاسبي فادح تتفاداه خوارزمية التقرير.

---

### 🔵 المثال الثاني: تفاوت أسعار البيع (خصومات وجملة وقطاعي)

لنفترض منتجاً تكلفة شرائه ثابتة **50 د.ل**، ولديك **10 قطع** في المخزن:

#### 1. سجل المبيعات:
* تم بيع **8 قطع** بسعر قطاعي عادي **100 د.ل/قطعة** (إجمالي = 800 د.ل).
* تم بيع **2 قطعة** لعميل مميز بسعر مخفض **60 د.ل/قطعة** (إجمالي = 120 د.ل).
* إجمالي الكمية المباعة = **10 قطع** | إجمالي المبيعات = **920 د.ل**.

---

#### 2. الحساب الدقيق (التقرير):
* ربح المبيعات العادية = $8 \times (100 - 50) =$ **400 د.ل**.
* ربح المبيعات المخفضة = $2 \times (60 - 50) =$ **20 د.ل**.
* **الربح الفعلي المحقق** = $400 + 20 =$ **420 د.ل**.

---

#### 3. الحساب بالمتوسطات:
* متوسط سعر البيع = $\frac{920}{10} = 92\text{ د.ل}$.
* متوسط سعر الشراء = $50\text{ د.ل}$.
* الربح = $(92 - 50) \times 10 = 42 \times 10 =$ **420 د.ل** (تتطابق فقط لأن التكلفة كانت ثابتة تماماً طوال الفترة).

---

### 🟠 المثال الثالث: أثر مرتجعات الزبائن (Sales Returns)

لنفترض أن عميلاً اشترى قطعة بسعر **100 د.ل** (تكلفتها **60 د.ل** - ربحها 40 د.ل)، ثم أعادها لاحقاً:

1. **في التقرير:**
   * عند إدخال المرتجع، يتم إلغاء ربح الفاتورة فوراً ($-\text{40 د.ل}$)، وتعود القطعة للمخزن بتكلفتها الأصلية (60 د.ل).
2. **في المعادلة اليدوية:**
   * إذا تم إرجاع القطعة بمبلغ مختلف أو خصم، فإن متوسط سعر البيع يتأثر بنسبة قد لا تعكس بالضبط إلغاء حركة البيع الأصلية.

## 🛠️ كيف تعمل الخوارزمية برمجياً في الكود؟

تتواجد الخوارزمية داخل الملف:
`app/Repositories/ReportRepository.php` في الدالة `stockStatus`:

```php
// 1. تجميع الأحداث بالترتيب الزمني (شراء = 1, بيع = 2, مرتجع زبون = 3, مرتجع مورد = 4)
usort($events, function($a, $b) {
    if ($a['date'] != $b['date']) return $a['date'] <=> $b['date'];
    if ($a['type'] != $b['type']) return $a['type'] <=> $b['type'];
    return $a['id'] <=> $b['id'];
});

// 2. تتبع رصيد المخزون وتكلفته المتحركة لحظياً
foreach ($events as $e) {
    $pid = $e['pid'];
    $st = &$state[$pid];
    $inRange = (!$dateFromFull || $e['date'] >= $dateFromFull);

    if ($e['type'] === 1) { // مشتريات: إعادة حساب متوسط التكلفة الجديد
        $st['qty'] += $e['qty'];
        $st['val'] += $e['val'];
        if ($st['qty'] > 0) $st['cost'] = $st['val'] / $st['qty'];
    } elseif ($e['type'] === 2) { // مبيعات: احتساب تكلفة البضاعة المباعة اللحظية والربح
        $cogs = $e['qty'] * $st['cost'];
        $st['qty'] -= $e['qty'];
        $st['val'] -= $cogs;
        if ($inRange) {
            $productProfits[$pid] += $e['val'] - $cogs;
        }
    } elseif ($e['type'] === 3) { // مرتجع مبيعات: خصم أثر الربح وإعادة التكلفة للمخزون
        $cor = $e['qty'] * $st['cost'];
        $st['qty'] += $e['qty'];
        $st['val'] += $cor;
        if ($inRange) {
            $productProfits[$pid] -= $e['val'] - $cor;
        }
    }
}
```

## 🎯 الخلاصة والتوصيات لمحلل البيانات

1. **الأعمدة الاسترشادية:**
   * أعمدة **متوسط سعر الشراء** و**متوسط سعر البيع** في الجدول هما مؤشرات عامة (Macro Indicators) تُعرض لإعطاء نظرة سريعة على اتجاهات الأسعار.
2. **عمود الربح:**
   * عمود **الربح** يمثل **المحصلة الدقيقة والفعلية لصافي التدفقات والأرباح المحققة** (Micro Transaction-Level Accounting).
3. **التوصية:**
   * اعتمد دائماً على قيمة الربح المسجلة في التقرير في إعداد القوائم المالية وتقييم أداء المنتجات، وتجنب الاعتماد على ضرب المتوسطات البسيطة لكونها غير دقيقة عند وجود تقلبات في الأسعار أو تعدد في شحنات التوريد.
