================================================================================
                    المرحلة 4: المستخدمون والعملاء والموردون
================================================================================

📋 نظرة عامة:
--------------
هذه المرحلة تُعرِّف من يستخدم النظام، من يشتري منك، ومن تشتري منه.

   users     → حسابات الدخول للنظام
   customers → العملاء الذين يشترون منك
   suppliers → الموردون الذين تشتري منهم

📌 ملاحظة مهمة — زبون نقدي:
   أول سجل يُنشأ في customers هو "زبون نقدي" (id=1).
   كل فاتورة بدون تحديد عميل تُنسب إليه تلقائياً.

📌 ملاحظة مهمة — مورد نقدي:
   أول سجل يُنشأ في suppliers هو "مورد نقدي" (id=1).
   كل فاتورة شراء بدون تحديد مورد تُنسب إليه تلقائياً.

================================================================================
                    🗂️ الجداول المستخدمة في هذه المرحلة
================================================================================

   1. users      → حسابات المستخدمين
   2. customers  → العملاء
   3. suppliers  → الموردون


================================================================================
                        1️⃣  users
================================================================================

📌 الوظيفة:
   تسجيل حسابات الأشخاص الذين يستخدمون النظام.
   كل عملية بيع مرتبطة بمستخدم — يعرف النظام من قام بالبيع.

📌 الحقول المهمة:
   name     → الاسم الكامل
   username → اسم الدخول (فريد)
   email    → البريد الإلكتروني (اختياري)
   password → كلمة المرور (مشفرة)
   role     → الدور (حالياً الكل admin)

📌 خطوات إنشاء مستخدم:

-- مثال: إضافة بائع
INSERT INTO users (name, username, password, role)
VALUES ('أحمد محمد', 'ahmed', 'hashed_password', 'admin');

-- مثال: إضافة مدير
INSERT INTO users (name, username, email, password, role)
VALUES ('محمد علي', 'admin', 'admin@store.com', 'hashed_password', 'admin');

✅ النتيجة: المستخدم جاهز لتسجيل الدخول وإنشاء الفواتير

📌 قاعدة:
   UNIQUE (username) — لا يمكن تكرار اسم الدخول
   UNIQUE (email)    — لا يمكن تكرار البريد الإلكتروني


================================================================================
                        2️⃣  customers
================================================================================

📌 الوظيفة:
   تسجيل بيانات العملاء لتتبع مشترياتهم.
   العميل اختياري في الفاتورة — البائع يحدده فقط إذا أراد.
   إذا لم يُحدد عميل → تُنسب الفاتورة لـ "زبون نقدي" تلقائياً.

📌 الحقول المهمة:
   name               → اسم العميل
   phone              → رقم الهاتف (إلزامي)
   email              → البريد الإلكتروني (اختياري)
   address            → العنوان (اختياري)
   is_active          → حالة النشاط

📌 الحقول المالية (cached — تُحدَّث تلقائياً من النظام):
   total_purchases    → إجمالي المشتريات
   total_paid         → إجمالي المدفوع
   total_returns      → إجمالي المرتجع
   total_settlements  → إجمالي التسويات
   total_debt         → إجمالي الديون الحالية


================================================================================
                        3️⃣  suppliers
================================================================================

📌 الوظيفة:
   تسجيل بيانات الموردين لتتبع المشتريات منهم.
   المورد إلزامي في فاتورة الشراء.
   إذا لم يُحدد مورد → تُنسب الفاتورة لـ "مورد نقدي" تلقائياً.

📌 الحقول المهمة:
   name               → اسم المورد
   phone              → رقم الهاتف (إلزامي)
   email              → البريد الإلكتروني (اختياري)
   address            → العنوان (اختياري)
   is_active          → حالة النشاط

📌 الحقول المالية (cached — تُحدَّث تلقائياً من النظام):
   total_purchases    → إجمالي ما اشتريته منه
   total_paid         → إجمالي ما دفعته له
   total_returns      → إجمالي ما أرجعه لك
   total_settlements  → إجمالي التسويات معه
   total_debt         → إجمالي ما تدين له به

📌 الفرق عن customers:
   الاتجاه معكوس — أنت المدين للمورد، والعميل مدين لك.
   أسماء الحقول متطابقة، الفرق يظهر في قراءة القيم فقط.


================================================================================
                    🔄 خطوات التنفيذ (بالترتيب)
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ الخطوة 1: إنشاء "زبون نقدي" (أول سجل إلزامي في customers)                │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: النظام (يُنشأ تلقائياً عند تهيئة النظام)
🔹 الشرط: يجب أن يكون id = 1 دائماً

INSERT INTO customers (name, is_active)
VALUES ('زبون نقدي', TRUE);
-- customer_id = 1

✅ النتيجة:
   كل فاتورة بدون تحديد عميل → customer_id = 1 تلقائياً

📌 قاعدة خاصة بزبون نقدي:
   - لا يمكن تعديله أو حذفه
   - الحقول المالية لا تُحدَّث عليه
   - لا يظهر في قائمة العملاء عند البيع


┌─────────────────────────────────────────────────────────────────────────────┐
│ الخطوة 2: إنشاء "مورد نقدي" (أول سجل إلزامي في suppliers)                │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: النظام (يُنشأ تلقائياً عند تهيئة النظام)
🔹 الشرط: يجب أن يكون id = 1 دائماً

INSERT INTO suppliers (name, phone, is_active)
VALUES ('مورد نقدي', '0000000000', TRUE);
-- supplier_id = 1

✅ النتيجة:
   كل فاتورة شراء بدون تحديد مورد → supplier_id = 1 تلقائياً

📌 قاعدة خاصة بمورد نقدي:
   - لا يمكن تعديله أو حذفه
   - الحقول المالية لا تُحدَّث عليه
   - لا يظهر في قائمة الموردين عند الشراء

================================================================================
                    📊 كيف يعمل "زبون نقدي" في الفاتورة
================================================================================

   البائع يفتح صفحة البيع
         ↓
   حقل العميل = "زبون نقدي" (افتراضي)
         ↓
   ┌─────────────────────────────────────────────────────┐
   │ البائع لم يغير العميل                               │
   │   → customer_id = 1 (زبون نقدي)                    │
   │   → لا تتبع مالي                                   │
   ├─────────────────────────────────────────────────────┤
   │ البائع اختار عميلاً من القائمة                      │
   │   → customer_id = العميل المختار                    │
   │   → تُحدَّث الحقول المالية تلقائياً                 │
   └─────────────────────────────────────────────────────┘

================================================================================
                        ⚠️ قواعد العمل المهمة
================================================================================

1.  ✅ "زبون نقدي" يجب أن يكون أول سجل في customers (id = 1)
2.  ✅ "مورد نقدي" يجب أن يكون أول سجل في suppliers (id = 1)
3.  ✅ "زبون نقدي" و"مورد نقدي" لا يُعدَّلان ولا يُحذفان
4.  ✅ الحقول المالية لا تُحدَّث على "زبون نقدي" أو "مورد نقدي"
5.  ✅ "زبون نقدي" لا يظهر في قائمة اختيار العملاء عند البيع
6.  ✅ "مورد نقدي" لا يظهر في قائمة اختيار الموردين عند الشراء
7.  ✅ UNIQUE (username) في users
8.  ✅ UNIQUE (phone) في customers وفي suppliers
9.  ✅ رقم الهاتف إلزامي عند إضافة عميل أو مورد
10. ✅ يمكن إضافة عميل أو مورد بدون بريد إلكتروني أو عنوان
