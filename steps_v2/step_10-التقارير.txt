================================================================================
                    1️⃣  تقرير حركة المنتج (Product Movement)
================================================================================

📌 الوظيفة:
   تتبع كل حركة مخزون لمنتج معين خلال فترة زمنية محددة.
   يُظهر رصيد أول الفترة، كل الحركات مرتبة زمنياً، ورصيد آخر الفترة.

📌 المدخلات (فلاتر):
   product_id   → المنتج (إجباري)
   date_from    → تاريخ البداية
   date_to      → تاريخ النهاية
   type         → نوع الحركة (all / purchase / sale / return_in / return_out / waste)

📌 المخرجات:
   opening_stock  → رصيد أول الفترة (stock قبل date_from)
   movements[]    → قائمة الحركات:
      date        → التاريخ
      type        → نوع العملية (شراء / بيع / مرتجع عميل / مرتجع مورد / تالف)
      quantity    → الكمية (موجبة = دخول، سالبة = خروج)
      unit_price  → السعر (unit_cost أو unit_price حسب النوع)
      reference   → المرجع (رقم الفاتورة أو السجل)
      balance     → الرصيد التراكمي بعد كل حركة
   closing_stock  → رصيد آخر الفترة

📌 مصادر الحركات:
```
purchase_items      → دخول مخزون  (+quantity)
invoice_items       → خروج مخزون  (-quantity)
invoice_return_items → دخول مخزون (+quantity)
purchase_return_items → خروج مخزون (-quantity)
waste_items         → خروج مخزون  (-quantity)
```

📌 حساب رصيد أول الفترة:
```
opening_stock = products.stock الحالي
              - SUM(purchase_items.quantity WHERE date >= date_from)
              + SUM(invoice_items.quantity WHERE date >= date_from)
              - SUM(invoice_return_items.quantity WHERE date >= date_from)
              + SUM(purchase_return_items.quantity WHERE date >= date_from)
              + SUM(waste_items.quantity WHERE date >= date_from)
```


================================================================================
                    2️⃣  تقرير المخزون الحالي (Stock Status)
================================================================================

📌 الوظيفة:
   لقطة فورية لحالة مخزون جميع المنتجات.
   يُبرز المنتجات التي وصلت للحد الأدنى أو تجاوزته.

📌 المدخلات (فلاتر):
   category_id  → التصنيف
   selling_type → نوع المنتج (tier_based / unit_priced)
   low_stock    → منتجات تحت الحد الأدنى فقط (boolean)

📌 المخرجات لكل منتج:
   name              → اسم المنتج
   category          → التصنيف
   stock             → الكمية الحالية
   min_stock         → الحد الأدنى
   status            → حالة التنبيه (ok / warning / critical)
   last_purchase_cost → آخر سعر شراء (من آخر purchase_item)
   last_sale_price   → آخر سعر بيع (من آخر invoice_item)

📌 قواعد حالة التنبيه:
```
stock > min_stock      → ok       (أخضر)
stock = min_stock      → warning  (برتقالي)
stock < min_stock      → critical (أحمر)
```


================================================================================
                    3️⃣  تقرير ديون العملاء (Customer Aging)
================================================================================

📌 الوظيفة:
   تحليل ديون العملاء وتصنيفها حسب عمر الدين.
   يساعد في تحديد العملاء الذين تأخروا في السداد.

📌 المدخلات (فلاتر):
   customer_id  → عميل محدد (اختياري — الكل إذا فارغ)
   date_to      → تاريخ المرجع للحساب (افتراضي: اليوم)

📌 المخرجات لكل عميل:
   name          → اسم العميل
   total_debt    → إجمالي الدين الحالي
   aging buckets → تصنيف الفواتير غير المسددة:
      current    → أقل من 30 يوم
      days_30_60 → من 30 إلى 60 يوم
      days_60_90 → من 60 إلى 90 يوم
      over_90    → أكثر من 90 يوم
   invoices[]    → تفاصيل الفواتير غير المسددة (unpaid / partial)

📌 قاعدة الحساب:
```
عمر الفاتورة = date_to - invoices.created_at
الفواتير المشمولة: payment_status IN ('unpaid', 'partial')
```

📌 المدخلات (فلاتر):
   date_from    → تاريخ البداية
   date_to      → تاريخ النهاية

================================================================================
                    1️⃣3️⃣  تقرير إجمالي الربح الإجمالي (Gross Profit)
================================================================================

📌 الوظيفة:
   حساب الربح الإجمالي خلال فترة.
   يعتمد على متوسط تكلفة الشراء لكل منتج (Weighted Average Cost).

📌 المدخلات (فلاتر):
   date_from    → تاريخ البداية
   date_to      → تاريخ النهاية
   category_id  → التصنيف

📌 المخرجات:
   total_revenue      → إجمالي المبيعات
   total_cogs         → إجمالي تكلفة البضاعة المباعة
   gross_profit       → الربح الإجمالي = total_revenue - total_cogs
   gross_margin_pct   → نسبة هامش الربح = (gross_profit / total_revenue) × 100
   by_product[]       → تفصيل لكل منتج

📌 طريقة حساب COGS:
```
لكل منتج:
   avg_cost = SUM(purchase_items.line_total) / SUM(purchase_items.quantity)
   cogs     = avg_cost × الكمية المباعة في الفترة
```

📌 ملاحظة:
   هذا تقدير مبسط يعتمد على المتوسط المتحرك (Weighted Average).
   لا يدعم FIFO في هذه المرحلة.

   تُحدَّث تلقائياً — لا فلاتر.

   today_purchases      → مشتريات اليوم
   today_waste_value    → قيمة التالف اليوم (تقديرية)
   today_cash_received  → المدفوعات النقدية المقبوضة اليوم
   today_cash_paid      → المدفوعات النقدية المدفوعة للموردين اليوم
   stock_change         → تغير المخزون الكلي اليوم (دخول - خروج)
   invoices_count       → عدد الفواتير اليوم
   new_customers        → عملاء جدد اليوم
