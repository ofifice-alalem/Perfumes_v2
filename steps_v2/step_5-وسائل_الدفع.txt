================================================================================
                    المرحلة 5: وسائل الدفع
================================================================================

📋 نظرة عامة:
--------------
هذه المرحلة تُعرِّف وسائل الدفع المتاحة في النظام.
وسائل الدفع مشتركة بين جميع العمليات المالية:
   - دفعات العملاء (payments)
   - تسويات العملاء (settlements)
   - دفعات الموردين (supplier_payments)
   - تسويات الموردين (supplier_settlements)

================================================================================
                    🗂️ الجداول المستخدمة في هذه المرحلة
================================================================================

   1. payment_methods → وسائل الدفع المتاحة


================================================================================
                        1️⃣  payment_methods
================================================================================

📌 الوظيفة:
   تعريف وسائل الدفع المتاحة في النظام.
   جدول مستقل يسمح بإضافة وسائل جديدة بدون تعديل في الكود.

📌 الحقول المهمة:
   name      → اسم الوسيلة (فريد)
   is_active → هل هي متاحة حالياً؟

📌 أمثلة:

   ┌──────────────────┬───────────┐
   │ name             │ is_active │
   ├──────────────────┼───────────┤
   │ نقدي             │ true      │
   │ بطاقة            │ true      │
   │ تحويل بنكي       │ true      │
   └──────────────────┴───────────┘


================================================================================
                    🔄 خطوات التنفيذ
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ إنشاء وسائل الدفع                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

🔹 الفاعل: Admin
🔹 الشرط: لا يوجد

INSERT INTO payment_methods (name, is_active) VALUES
('نقدي',        true),
('بطاقة',       true),
('تحويل بنكي',  true);

✅ النتيجة: وسائل الدفع جاهزة للاستخدام في جميع العمليات المالية


================================================================================
                        ⚠️ قواعد العمل المهمة
================================================================================

1. ✅ UNIQUE (name) — لا يمكن تكرار اسم الوسيلة
2. ✅ is_active = false → لا تظهر في أي واجهة دفع
3. ✅ يمكن إضافة وسيلة جديدة في أي وقت بدون تعديل في الكود
4. ✅ لا يمكن حذف وسيلة مرتبطة بدفعات أو تسويات موجودة


================================================================================
                        🎯 ما اكتمل بعد هذه المرحلة
================================================================================

✅ وسائل الدفع جاهزة للاستخدام في:
   - دفعات العملاء
   - تسويات العملاء
   - دفعات الموردين
   - تسويات الموردين

❌ لم يُضف بعد:
   - المشتريات والمخزون
   - الفواتير والبيع
