================================================================================
                    المرحلة 12: نظام النسخ الاحتياطية (Backup System)
================================================================================

📋 نظرة عامة:
--------------
نظام النسخ الاحتياطية يتيح إنشاء نسخ احتياطية لقاعدة البيانات،
واستعادتها عند الحاجة، مع إمكانية رفع نسخ خارجية وتحميلها.

📌 نوع النسخة الاحتياطية:
   database  → قاعدة البيانات فقط (SQL dump)

📌 ملاحظة:
   المشروع لا يحتوي على ملفات مرفوعة من المستخدم.
   اللوغو ثابت في public/images/logo.jpg ولا يحتاج نسخ احتياطي.
   لذلك نسخة قاعدة البيانات فقط تكفي.

📌 مكان الحفظ:
   storage/app/backups/database/   → نسخ قاعدة البيانات

📌 تسمية الملفات:
   backup_{Y-m-d_H-i-s}_database.zip
   مثال: backup_2026-05-09_14-30-00_database.zip

📌 الصلاحية: super-admin فقط


================================================================================
                    🔄 آلية العمل
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ إنشاء نسخة احتياطية                                                        │
└─────────────────────────────────────────────────────────────────────────────┘

1. إنشاء ملف ZIP في storage/app/backups/database/
2. جلب كل الجداول عبر SHOW TABLES
3. لكل جدول: SHOW CREATE TABLE + INSERT INTO VALUES
4. الكتابة على دفعات (chunk 500) لتجنب نفاد الذاكرة
5. حفظ الـ SQL في ملف مؤقت ثم إضافته للـ ZIP كـ database.sql
6. إذا كانت هناك ملاحظة: تُحفظ كـ note.txt داخل الـ ZIP
7. حذف الملف المؤقت .sql
8. إرجاع الملف للتحميل مباشرة

┌─────────────────────────────────────────────────────────────────────────────┐
│ استعادة نسخة احتياطية                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

1. البحث عن الملف في المجلدات الثلاثة
2. استخراج الـ ZIP إلى مجلد مؤقت (storage/app/restore_temp)
3. إذا وُجد database.sql:
   - SET FOREIGN_KEY_CHECKS=0
   - تقسيم الـ SQL إلى statements منفصلة (مع مراعاة الـ strings)
   - تنفيذ كل statement عبر PDO مباشرة
   - SET FOREIGN_KEY_CHECKS=1
4. إذا وُجد مجلد storage/:
   - حذف storage/app/public الحالي
   - نسخ المجلد المستخرج إلى storage/app/public
5. حذف المجلد المؤقت
6. إعادة التوجيه مع رسالة نجاح

┌─────────────────────────────────────────────────────────────────────────────┐
│ رفع نسخة خارجية                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

1. رفع ملف .zip (حد أقصى 512MB)
2. حفظ الملف في storage/app/backups/database/

┌─────────────────────────────────────────────────────────────────────────────┐
│ عرض قائمة النسخ                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

1. مسح storage/app/backups/database/ وجمع كل ملفات .zip
2. لكل ملف: قراءة note.txt من داخل الـ ZIP إن وُجد
3. ترتيب النسخ من الأحدث للأقدم
4. عرضها في جدول واحد


================================================================================
                    🗂️ لا جداول جديدة
================================================================================

📌 النظام لا يحتاج أي جداول في قاعدة البيانات.
   كل شيء يُحفظ كملفات ZIP في storage/app/backups/


================================================================================
                    🔄 خطوات التنفيذ (بالترتيب)
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ الخطوة 1: BackupController                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

app/Http/Controllers/BackupController.php

الدوال:
   index()              → عرض قائمة النسخ
   create(Request)      → إنشاء نسخة جديدة وتحميلها
   restore($filename)   → استعادة نسخة محددة
   download($filename)  → تحميل نسخة محددة
   delete($filename)    → حذف نسخة محددة
   upload(Request)      → رفع نسخة خارجية

الدوال المساعدة (private):
   formatBytes($bytes)              → تحويل الحجم لصيغة مقروءة
   restoreLargeSQL($sqlFile)        → تنفيذ SQL كبير بأمان

إعدادات الأداء:
   set_time_limit(300)              → للإنشاء
   set_time_limit(0)                → للاستعادة
   ini_set('memory_limit', '512M')  → للإنشاء
   ini_set('memory_limit', '1G')    → للاستعادة

┌─────────────────────────────────────────────────────────────────────────────┐
│ الخطوة 2: Routes                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

Route::middleware('role:super-admin')->prefix('backups')->name('backups.')->group(function () {
    Route::get('/',                    [BackupController::class, 'index'])   ->name('index');
    Route::post('/create',             [BackupController::class, 'create'])  ->name('create');
    Route::post('/upload',             [BackupController::class, 'upload'])  ->name('upload');
    Route::post('/restore/{filename}', [BackupController::class, 'restore']) ->name('restore');
    Route::get('/download/{filename}', [BackupController::class, 'download'])->name('download');
    Route::delete('/{filename}',       [BackupController::class, 'delete'])  ->name('delete');
});

┌─────────────────────────────────────────────────────────────────────────────┐
│ الخطوة 3: Frontend                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

resources/js/pages/Backups/Index.tsx

المكونات:
   - زران: إنشاء نسخة | رفع نسخة
   - جدول النسخ: اسم الملف | التاريخ | الحجم | الإجراءات | الملاحظة
   - Modal إنشاء: حقل ملاحظة اختياري + تأكيد
   - Modal استعادة: شريط تقدم وهمي أثناء الانتظار
   - Modal رفع: اختيار ملف .zip

┌─────────────────────────────────────────────────────────────────────────────┐
│ الخطوة 4: إنشاء مجلد التخزين                                               │
└─────────────────────────────────────────────────────────────────────────────┘

mkdir -p storage/app/backups/database

📌 يُنشأ تلقائياً عند أول نسخة احتياطية إذا لم يكن موجوداً.

================================================================================
                    ⚠️ قواعد العمل المهمة
================================================================================

1.  ✅ الصلاحية: super-admin فقط
2.  ✅ الإنشاء يُرجع الملف للتحميل مباشرة (لا يُحفظ فقط)
3.  ✅ الملف يُحفظ أيضاً في storage/app/backups/ للرجوع إليه لاحقاً
4.  ✅ الاستعادة تطلب تأكيد مزدوج قبل التنفيذ
5.  ✅ الاستعادة تستبدل كل البيانات الحالية بالكامل
6.  ✅ SQL يُنفَّذ عبر PDO مباشرة (لا عبر Eloquent) لدعم الـ statements الكبيرة
7.  ✅ FOREIGN_KEY_CHECKS=0 أثناء الاستعادة لتجنب أخطاء الـ constraints
8.  ✅ الملاحظة تُحفظ كـ note.txt داخل الـ ZIP نفسه
9.  ✅ حد رفع الملفات: 512MB
10. ✅ chunk(500) عند قراءة البيانات لتجنب نفاد الذاكرة
